## LinkedIn project description

I developed a working procurement prototype to explore a practical control problem: connecting purchase order status with a consistent, inspectable event history.

The application follows orders through creation, approval, delivery and verification. A Python API and SQLite database support the browser dashboard, while a SHA-256 event chain provides a separate check for altered event values. Four automated tests cover order creation, the complete workflow, invalid transitions and tamper detection.

The repository includes a business case, process diagrams, setup guide and screenshots. This is a portfolio demonstration using synthetic data; it is not an aerospace certification system or a live ERP/blockchain integration.
